AutoCar SLAM
============

Drop the images for this project into THIS folder, using these exact filenames.
The site picks them up automatically — no code change needed.

  car.jpg
      [photo] Photo of the assembled car — LiDAR on top, Pi and ESP32 visible

  map.png
      [screenshot] Foxglove screenshot of a completed room map with scan points overlaid

  ros-graph.png
      [diagram] ROS 2 node graph: micro-ROS, ticks_odom_node, lidar, slam, teleop

  mapping-run.gif
      [screenshot] Short GIF or still of the map filling in during a driving run

Aim for ~1600px on the long edge. Images are cropped with object-cover to fit the frame.
