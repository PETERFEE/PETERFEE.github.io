The Beauty and Math -- live demo
================================

Copy index.html from your repo:

  https://github.com/PETERFEE/The-Beaty-and-Math

into THIS folder, so the final path is:

  public/demos/message-heart/index.html

That's the whole step -- the project page embeds it automatically. The file is
self-contained and pulls Three.js from cdnjs, so nothing else needs installing.

The page shows a "Run it here" poster rather than auto-loading the demo, because
building a few thousand particles unprompted is rude to anyone just scrolling.
