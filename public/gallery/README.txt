Gallery-only tile images
========================

Most gallery tiles reuse the image from that project's detail section, so you
only supply those once (see public/projects/<slug>/).

These two tiles have no detail section, so their images live here:

  sv-tutorial.png    SystemVerilog Tutorial tile
  devotee.png        Devotee tile

Tiles are cropped to 4:3, so roughly 1200x900px works well.
